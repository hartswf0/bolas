# WYGWYL workshop: experiments and indexes

Work from the WYGWYL build, copied here so it can be read beside the CRASH LAB pages. Nothing here is linked from the site navigation yet.

- **set-pieces/** the set-piece swarm: `registry.json` (one record per set piece: grade, category, plane, contact, affordances, provenance), `query.py`, `README.md`, the category atlases, and the staged proof scenes with their critic repair notes (`proof/REPAIR.md`).
- **studio/** the puppet studio: the performance layer and proofs 01–03 (bent rigs, pose selection, exposure sheets), the swarm audit (`AUDIT.md`, `audit_page/index.html`), and the coverage table.
- **joints/** the joint lab: all blind-critic verdicts for rounds 1–8 (`critic_verdicts.json`), the style-anchored critic rubric (`CRITIC_V2.md`), and the round 7 and 8 status boards.

Not included: the cut-out source images (`shots/kits/cut`), the embedding caches, and the intermediate renders. The registry points at source paths in the WYGWYL build repository, `shots/kits/cut/`.
