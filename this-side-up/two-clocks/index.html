How it was made

  1. Write the story as times on screen.
  2. Draw the world's rate as a curve and integrate it.
  3. Run everything but Boone and the camera on world seconds.
  4. Make the sound from the same events.

What this case teaches

  1. Any object can be asked which clock it is on.

How it differs. v3 slowed everything. v4 splits the world from Boone.
