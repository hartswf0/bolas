The Physical

Can cartoon gags be written as joint motions and audited?

Bola reports for a physical: 47 cartoon proofs in six acts, with the joints each proof drives audited underneath.

How it was made

  1. Write each gag as a proof: what the body does and which joints carry it.
  2. Render each proof and print a frame strip.
  3. Audit which joints actually moved in each proof against the ones the gag claimed.

What this case teaches

  1. A gag is a list of joints in an order. Writing it that way shows which gags are really the same gag.
  2. The audit catches proofs that look busy but move nothing new.
  3. This is the first case with a named character, so the body now has a size and a manner to keep consistent.

How it differs. The range test pushed joints to their limits. The Physical asks what those joints are for in a scene.
