Bolas pencil test

Can the motion be checked before anything is drawn?

A page that acts out the three experiments of From Imagetext to Worldtext with ball-and-cord figures, with the text beside the action, beat by beat.

How it was made

  1. Split the work into two rooms: a skeletal pencil-test room, where only joints move, and a studio room, where figures are drawn.
  2. Key every beat as a stick figure and log it on an X-sheet.
  3. Pass a pose to the studio room only after it clears the skeletal gate.

What this case teaches

  1. Timing and staging are cheap to change on a skeleton and expensive to change on finished drawings, so they are settled first.
  2. The gate is a rule, not a judgement call: a pose moves on only when it passes.
  3. Putting the source text beside each beat turns every frame into a check: does this beat say what the line says?

How it differs. This is the only case with no character yet. The figures are generic balls and cords, so the lesson is about method, not about a body.
