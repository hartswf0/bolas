How it was made

  1. Open on the prompt being typed; Odysseus stands on it and stamps it into NOBODY.
  2. Build a brand kit: palette, meander border, vase cartouche, title stamp.
  3. Add a third voice of gold ink notes on the captions.

What this case teaches

  1. Breaking the fourth wall is a set of specific devices, each listed: the prompt on screen, ink notes, looks to camera, using the credits as furniture.
  2. A brand kit written as code keeps every later episode consistent.
  3. Four short acts from four books test the format before any one story is told at length.

How it differs. The tests were single shots. This is the first full episode with a structure, a title and credits.
