What if each scene needs only one line?

How it was made

  1. Find the line where power shifts in each scene.
  2. Play everything else wide; go tight only for the line and hold after it.
  3. Silence the score two seconds before the line; one low note after it.
  4. Remove all ink notes and labels.

What this case teaches

  1. "I don't need all of the lines, I need the line." One rule changes framing, gesture, sound and writing at once.
  2. A single held gesture can carry meaning that a caption used to carry.
  3. Taking things away (notes, labels) is tested as carefully as adding them.

How it differs. Episodes 1 to 3 added devices. Episode 4 removes them and keeps one line.
