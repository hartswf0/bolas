How it was made

  1. Make every gift, the ship, the olive and the cave real 3D boxes in the rig's world coordinates.
  2. Write a log of commands and checks beside the frame.
  3. A node turns to colour only when a hand holds it (the Episode 6 grip latch); otherwise it resets to grey box.

What this case teaches

  1. Every number in the log comes from code reading the rig's joints and the boxes, so the on-screen check is real.
  2. Seven agents loop the same line seven times; each fails a different check until one locks.
  3. The production method (blockout, check, ink) is the plot.

How it differs. Episode 6 fixed the grip. Episode 7 uses the grip as the test that lets the world exist.
