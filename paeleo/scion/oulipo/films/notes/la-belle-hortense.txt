A typographic mystery in six modules about the key left on the bench. Each module has six sentences, and each uses exactly one motif (key, bell, coat, bench, receipt, locked door). Their order comes from applying the sextine permutation [6,1,5,2,4,3] to the previous module; the script refuses to run if a module breaks this. Motif chips visibly travel to their new slots, and each motif has its own synthesized sound, so the reordering can be heard too. The folded coat is background in module 1 and evidence by module 5. A pause invites a guess before the reveal; a final grid shows the seventh turn returning to the start.
