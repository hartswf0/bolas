# Oulipo SCION

Twenty-five production swarm prompts and one system-instruction compiler.

[Open the operator](https://hartswf0.github.io/bolas/paeleo/scion/oulipo/).

Edit the entries in `catalogue/` and run `python3 build.py` from this directory to regenerate the catalog, individual pages, and both prompt formats.
