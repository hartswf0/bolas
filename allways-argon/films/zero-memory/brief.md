# ZERO MEMORY (An editor forgets)

**Concept:** An editor repeatedly forgets the sequence it has just made, while its archive remains available. The audience begins to remember more of the film than its maker.

**Proposed First Proof:** Use a fixed collection of twelve short excerpts to build a ninety-second experiment. Give the editor access to the same collection throughout, but reset its declared working history at three visible boundaries. Keep a separate audit log inaccessible to that editing state. Allow repeated selections to remain, then place an intact recurrence beside a changed one in the final passage. Sound should make returning material recognizable without pretending that the underlying model has forgotten its training.

**Boundary Note:** Requires a new memory-reset policy and external audit log. Persistent archive access, model training, working history, and the spectator’s memory are different things.

**Primary SCION Operator:** SCION 106 — Network Effect — Bounded Attention, Unfinishable Archive

**Creative Theorem:** Use a fixed collection of short excerpts. Reset the editor's declared working history at three visible boundaries while keeping a separate external audit log. Allow repeated selections to recur, then place an intact recurrence beside a changed one.
