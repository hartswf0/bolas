# ZERO MEMORY

**Concept · An editor forgets**

An editor repeatedly forgets the sequence it has just made, while its archive remains available. The audience begins to remember more of the film than its maker.

**First proof.** Use a fixed collection of twelve short excerpts to build a ninety-second experiment. Give the editor access to the same collection throughout, but reset its declared working history at three visible boundaries. Keep a separate audit log inaccessible to that editing state. Allow repeated selections to remain, then place an intact recurrence beside a changed one in the final passage. Sound should make returning material recognizable without pretending that the underlying model has forgotten its training.

**Methods.** Primary: SCION 106 · Network Effect — Bounded Attention, Unfinishable Archive. Supporting: SCION 067 · (nostalgia) — Anticipated Image, Vanishing Evidence.

**Development boundary.** Requires a new memory-reset policy and external audit log. Persistent archive access, model training, working history, and the spectator’s memory are different things.

## Primary operator SCION 106: Network Effect — Bounded Attention, Unfinishable Archive

Theorem: Make finite experience time confront more playable material than it can contain, then compose an ending from the visitor's actual route. Distinguish opening an item from completing its playback without claiming to measure attention or understanding.

Acceptance criteria:
- The available media exceeds the budget, while reported exploration states match the actual route.
- Pause visibly suspends both time and progression, with exit always usable.
- The coda composes the actual route rather than inventing incompleteness or ending as an access error.
- The untimed index offers a different way of attending without rewriting session results.
- Adjustable audio remains intelligible; counts imply neither understanding nor a psychological diagnosis.
