The Physical.

Bola reports for a physical. Every test goes wrong in a cartoon way, and every wrong turn is a proof: that one skeleton can walk, reach, lift, slip, take, sulk, rage, swoon and tell a story without words. 47 proofs in six acts, played straight through like an episode, scored like a fitness test, with the joints and gestures each one drives audited underneath.

PROOF SHEET

    Translation audit

    Each row is a proof, each column a channel of the rig. A cell is filled in proportion to how far that channel travelled during the proof, measured from the solved joints, not from the script. If a gag claims to be about the knee, the knee column has to light up. The red line is the playhead.
